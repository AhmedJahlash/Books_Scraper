# Books Scraper

A Python project that scrapes book data from Books to Scrape.

## Features

- Scrape all 50 pages
- Extract title
- Extract price
- Extract availability
- Save data to CSV
- Save data to SQLite
- Search books
- Show statistics

## Technologies

- Python
- Requests
- BeautifulSoup
- SQLite
- CSV
